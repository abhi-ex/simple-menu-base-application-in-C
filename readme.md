# Simple Menu-Based Calculator

This project is a simple C program that performs basic arithmetic operations based on user input.

## Features
- Addition
- Subtraction
- Multiplication
- Division

## How it works
1. Enter the first number.
2. Enter the second number.
3. Choose an operation from the menu.
4. The program displays the result.

## Compile
```bash
gcc pr8.c -o pr8.exe
```

## Run
```bash
./pr8.exe
```

If the second number is zero while choosing division, the program displays a safe error message instead of crashing.
